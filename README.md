# SH Mock Tests – IELTS Practice Platform

**Live Demo:** [https://sh-mock-tests.vercel.app](https://sh-mock-tests.vercel.app)

A modern, password-protected IELTS Academic mock test platform built for **Shreehari Education Consultant Pvt. Ltd.**

Students can practice full-length mock tests with separate modules for **Listening**, **Reading**, and **Writing**.

---

## Features

- **10 Full Mock Tests** (Mock Test 1 – Mock Test 10)
- **IELTS Academic** format
- Separate modules:
  - **Listening** – 40 questions · 4 sections · ~30 minutes
  - **Reading** – 40 questions · 3 passages · 60 minutes
  - **Writing** – Task 1 + Task 2 · 60 minutes
- Clean, modern, and mobile-friendly UI
- Password protection for each test
- Instant access after entering the correct password
- Hosted on Vercel for fast global delivery

---

## How to Use

1. Visit the homepage: [https://sh-mock-tests.vercel.app](https://sh-mock-tests.vercel.app)
2. Select any Mock Test (1–10)
3. Enter the password provided by Shreehari
4. Choose the module you want to practice (Listening / Reading / Writing)
5. Start the test
